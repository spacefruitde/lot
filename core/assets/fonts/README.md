# Planschrift

`osifont-lgpl3fe.ttf` ist osifont, eine Schrift im Stil von DIN EN ISO 3098, unverändert übernommen.

- Quelle: https://github.com/hikikomori82/osifont (Stand 16.04.2026), Quelltext der Schrift dort als `.sfd`
- Lizenz: LGPL-3.0 mit GPL-Font-Ausnahme (Text in der Namenstabelle der Schrift). Das Einbetten in Dokumente wie PDFs macht diese nicht lizenzpflichtig.
- Lot lädt die Datei zur Laufzeit und baut sie nicht in das Programm ein. Siehe `docs/entscheidungen/0011-planschrift-osifont.md`.
